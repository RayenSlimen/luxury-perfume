Tech stack:
- Frontend: React.js (functional components + hooks)
- Styling: Tailwind CSS (luxury black, gold, white theme)
- Backend: Node.js with Express
- Database: PostgreSQL

Language:
- The entire user interface must be in French (buttons, labels, messages, pages)
- Use professional and elegant French wording

Brand identity:
- Velmora represents luxury, elegance, mystery
- Slogan: "Ressentez la puissance de l’élégance"

Design requirements:
- Ultra premium UI inspired by luxury brands (Dior, Chanel, Tom Ford)
- Dark mode (black background)
- Gold accents and smooth gradients
- Minimalist and clean layout
- Smooth animations and hover effects
- High-end typography

Pages to generate:

1. Accueil:
- Hero section avec image parfum luxe + slogan
- Produits populaires
- Meilleures ventes

- Footer élégant

2. Produits:
- Grille moderne des parfums

3. Détails produit:

4. Panier:
- Liste des produits

- Total

5. Authentification:
- Page Connexion
- Page Inscription
- JWT authentication

6. Dashboard Admin:
- Ajouter / modifier / supprimer produits

- REST API avec Express
- CRUD produits

- Gestion commandes

Database schema (PostgreSQL):
